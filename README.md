
# Distracted Website

Static band website for Distracted, Arnhem.

## Files

- index.html — Website content and SEO
- style.css — Layout, colors, typography and responsive design
- script.js — Photo gallery navigation
- images/ — Band photography

## Update the booking email

Open index.html and search for:

YOUR-EMAIL@example.com

Replace it with the actual booking email address.

## Update Instagram and Spotify

Open index.html and search for:

YOUR-INSTAGRAM
YOUR-SPOTIFY-ID

Replace these with the actual profile details.

## Replace the gallery placeholders

Add your photographs to the images folder.

Use these exact filenames:

- distracted-01.jpg
- distracted-02.jpg
- distracted-03.jpg
- distracted-04.jpg

Recommended:
- Landscape photographs
- High-quality JPG or WebP
- Around 1800px wide
- Keep file sizes optimized for web

The placeholders automatically disappear when the corresponding
photographs load successfully.

## Update website text

All website text can be edited directly in index.html.

## Change colors

Open style.css.

All main colors are defined at the top under :root.

## Local preview

Simply open index.html in your browser.

No installation or build process required.

## Publish with GitHub Desktop

1. Create a public GitHub repository.
2. Add this entire project folder.
3. Commit your changes.
4. Push to GitHub.

## Deploy with Netlify

1. Log in to Netlify.
2. Select Add new site > Import an existing project.
3. Connect your GitHub repository.
4. Set the publish directory to the repository root.
5. Leave the build command empty.
6. Deploy.

The site is now live.

Future changes can be published by committing and pushing
your updates through GitHub Desktop.
